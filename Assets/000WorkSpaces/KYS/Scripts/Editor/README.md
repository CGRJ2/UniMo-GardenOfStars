# KYS 에디터 도구 가이드

## 개요

KYS 프로젝트의 로컬라이제이션과 UI 관리를 위한 Unity 에디터 도구들입니다.

## 도구 목록

### 1. 프리팹 키 추출기 (PrefabLocalizationKeyExtractor)

**메뉴**: `KYS > 프리팹 키 추출기`

프리팹에서 로컬라이제이션 키를 추출하고 관리하는 도구입니다.

#### 주요 기능
- **선택된 프리팹에서 키 추출**: Project 창에서 프리팹을 선택 후 키 추출
- **모든 UI 프리팹에서 키 추출**: 프로젝트의 모든 UI 프리팹에서 키 추출
- **특정 폴더의 프리팹에서 키 추출**: 지정된 폴더의 프리팹들에서 키 추출
- **결과를 CSV로 내보내기**: 추출된 키들을 CSV 파일로 내보내기
- **검색 필터**: 프리팹 이름이나 키 이름으로 검색
- **프리팹 선택**: 결과에서 프리팹을 바로 선택

#### 사용법
1. Unity 메뉴에서 `KYS > 프리팹 키 추출기` 선택
2. 원하는 추출 방법 선택 (선택된 프리팹, 모든 UI 프리팹, 특정 폴더)
3. 결과 확인 및 필요시 CSV로 내보내기

### 2. 로컬라이제이션 키 관리자 (LocalizationKeyManager)

**메뉴**: `KYS > 로컬라이제이션 키 관리자`

CSV 파일의 로컬라이제이션 키를 관리하는 도구입니다.

#### 주요 기능
- **CSV 데이터 새로고침**: CSV 파일에서 키 데이터 다시 로드
- **중복 키 검사**: CSV에서 중복된 키 찾기
- **누락된 키 검사**: 프리팹에 있지만 CSV에 없는 키 찾기
- **프리팹에서 누락된 키 자동 추가**: 누락된 키들을 CSV에 자동 추가
- **CSV 백업 생성**: 현재 CSV 파일의 백업 생성
- **키 추가/삭제**: 개별 키 추가 및 삭제
- **통계 정보**: 총 키 개수, 중복 키 개수, 누락된 키 개수 표시

#### 사용법
1. Unity 메뉴에서 `KYS > 로컬라이제이션 키 관리자` 선택
2. CSV 파일 경로 확인 및 필요시 변경
3. 원하는 검사 기능 실행
4. 결과 확인 및 필요시 키 추가/삭제

### 3. UI 인스펙터 헬퍼 (UIInspectorHelper)

**위치**: BaseUI 컴포넌트의 인스펙터

BaseUI 컴포넌트의 인스펙터에 추가되는 헬퍼 도구입니다.

#### 주요 기능
- **로컬라이제이션 정보**: AutoLocalization 키들과 번역 존재 여부 표시
- **UI 요소 정보**: 모든 UI 요소들과 AutoLocalizedText 컴포넌트 존재 여부 표시
- **UI 요소 새로고침**: UI 요소 캐시 새로고침
- **로컬라이제이션 키 출력**: 콘솔에 로컬라이제이션 키 정보 출력
- **누락된 키 CSV에 추가**: 누락된 키들을 CSV에 자동 추가
- **AutoLocalization 설정**: TextMeshProUGUI 컴포넌트에 AutoLocalizedText 자동 추가

#### 사용법
1. BaseUI를 상속받는 컴포넌트 선택
2. 인스펙터 하단의 "🔧 KYS UI 헬퍼" 섹션 확인
3. 필요한 기능 버튼 클릭

### 4. AutoLocalizedText 인스펙터 헬퍼 (AutoLocalizedTextInspector)

**위치**: AutoLocalizedText 컴포넌트의 인스펙터

AutoLocalizedText 컴포넌트의 인스펙터에 추가되는 헬퍼 도구입니다.

#### 주요 기능
- **현재 키 표시**: 현재 설정된 로컬라이제이션 키 표시
- **현재 텍스트 표시**: 현재 표시되고 있는 텍스트 표시
- **번역 존재 여부**: 해당 키의 번역이 CSV에 존재하는지 표시
- **텍스트 새로고침**: AutoLocalization 다시 활성화
- **키를 CSV에 추가**: 현재 키를 CSV에 추가

#### 사용법
1. AutoLocalizedText 컴포넌트가 있는 GameObject 선택
2. 인스펙터 하단의 "🔤 AutoLocalizedText 헬퍼" 섹션 확인
3. 필요한 기능 버튼 클릭

## 사용 시나리오

### 시나리오 1: 새로운 UI 프리팹 생성 후 로컬라이제이션 설정

1. **프리팹 키 추출기**로 새 프리팹에서 키 추출
2. **로컬라이제이션 키 관리자**로 누락된 키 확인
3. **UI 인스펙터 헬퍼**로 AutoLocalization 설정
4. **AutoLocalizedText 인스펙터 헬퍼**로 개별 키 관리

### 시나리오 2: 기존 UI의 로컬라이제이션 점검

1. **로컬라이제이션 키 관리자**로 중복 키 및 누락된 키 검사
2. **프리팹 키 추출기**로 전체 프로젝트 키 추출
3. **UI 인스펙터 헬퍼**로 개별 UI 컴포넌트 점검

### 시나리오 3: CSV 파일 관리

1. **로컬라이제이션 키 관리자**로 CSV 백업 생성
2. 누락된 키 자동 추가
3. 중복 키 정리
4. 필요시 키 삭제

## 주의사항

1. **CSV 파일 경로**: 기본 경로는 `Assets/000WorkSpaces/KYS/Scripts/UI/Localization/LanguageData.csv`입니다.
2. **백업 생성**: CSV 파일 수정 전에 반드시 백업을 생성하세요.
3. **Undo 지원**: UI 인스펙터 헬퍼의 AutoLocalization 설정은 Undo를 지원합니다.
4. **에디터 전용**: 이 도구들은 Unity 에디터에서만 작동합니다.

## 문제 해결

### CSV 파일을 찾을 수 없는 경우
- **로컬라이제이션 키 관리자**에서 CSV 파일 경로를 올바르게 설정하세요.
- CSV 파일이 실제로 존재하는지 확인하세요.

### 키가 추출되지 않는 경우
- 프리팹에 `AutoLocalizedText` 컴포넌트가 있는지 확인하세요.
- UI 요소의 이름이 올바르게 설정되어 있는지 확인하세요.

### 번역이 표시되지 않는 경우
- **AutoLocalizedText 인스펙터 헬퍼**에서 번역 존재 여부를 확인하세요.
- CSV 파일에 해당 키의 번역이 있는지 확인하세요.
